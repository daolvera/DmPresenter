# DM Presenter

DM-only Control window plus a borderless Presentation window you share to Discord.

```
npm install
npm start
```

1. The frame is HTML/CSS plus the art in `assets/` (columns, eye, runes, wings). The two plaque texts (title and location) are edited in the Control window and saved between runs.
2. In Discord: Share Screen > Application Window > **DM Presenter — Presentation**, and enable **Also Share Application Audio**.
3. Use the Control window for media, banner, and audio. Settings persist between launches.

The Presentation window has no title bar. Move it with Alt+Space > Move (or Win+arrow keys); its position is remembered.

Maps: click an image, then use the Live view in Control. Wheel zooms, drag pans (Pan tool, or middle/right mouse in any tool), Draw/Erase add and remove marks. The Presentation window mirrors it. Marks are kept per image until the app closes.
